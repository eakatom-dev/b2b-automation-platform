## Product

### Cloud-Native B2B Automation & Integration Platform

A platform for businesses and teams to connect services and automate workflows between systems.

The long-term product will allow users to create integrations and workflows that move data or trigger actions between different services.

The product will grow gradually throughout this learning roadmap, starting as a static web interface and later expanding into a full-stack, cloud-native platform.

### Current Stage

Stage 0 focuses on defining the product, creating its initial architecture sketch, and building the first landing page skeleton.
